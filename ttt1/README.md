# Webdesigner Portfolio

一个现代化的网页设计师作品集网站，仿制自 eduardbodak.com

## 特性

- ✨ 流畅的动画效果
- 📱 完全响应式设计
- 🎨 现代化的 UI 设计
- ♿ 注重无障碍访问
- ⚡ 使用 Vite 构建，速度快

## 技术栈

- React 18
- Vite
- TailwindCSS
- Framer Motion
- Lucide Icons

## 安装和运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 项目结构

```
src/
├── components/     # React 组件
├── styles/        # 样式文件
├── App.jsx        # 主应用组件
└── main.jsx       # 入口文件
```
