# 图片说明

## OIP.webp 背景图片

请将 `OIP.webp` 图片文件放置在此目录下 (`frontend/public/images/OIP.webp`)。

### 推荐图片规格：
- **格式**: WebP
- **尺寸**: 1920x1080 或更高分辨率
- **内容**: 适合作为登录页面背景的图片
- **文件大小**: 建议 < 2MB

### 如何添加图片：
1. 将您的背景图片重命名为 `OIP.webp`
2. 复制到 `frontend/public/images/` 目录
3. 刷新登录页面即可看到效果

### 当前效果：
- 登录页面已配置为使用此背景图片
- 图片会自动适应屏幕尺寸 (cover)
- 添加了半透明渐变遮罩以确保文字可读性
- 登录卡片有毛玻璃效果

### 如果图片不存在：
页面将显示原来的渐变背景，不会报错。
